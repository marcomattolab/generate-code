AI-Powered GitHub Project Generator

Rapidly scaffold full-stack applications from a simple configuration.

Overview

  • What is it? A powerful tool that automates the creation of modern web applications.
  • Core Idea: Define your data models once in a simple JSON file, and the generator builds the entire application stack.
  • Key Features:
    • Full-stack generation (Frontend + Backend)
    • Support for multiple frontend frameworks (Angular, React)
    • CI/CD and Docker support out-of-the-box
    • AI-powered configuration

The Backend Generator (Spring Boot)

  • Technology: Java with Spring Boot & Maven
  • Database: PostgreSQL integration
  • Architecture:
    • RESTful API for each entity
    • Clear separation of concerns (Controller, Service, Repository)
    • JPA for data persistence
    • DTO pattern for clean API design

The Frontend Generator (Angular & React)

  • Flexibility: Choose your preferred framework in the project configuration.
  • Angular: Modern, standalone components, PrimeNG for UI, Signal-based state management.
  • React: Standard `create-react-app` base, `axios` for API communication, `react-router-dom` for navigation.

CI/CD & DevOps

  • Containerization: Dockerfiles for both frontend and backend.
  • Orchestration: `docker-compose.yml` to run the entire stack.
  • Includes: PostgreSQL, Nginx, Keycloak (optional), Prometheus & Grafana (optional).

The AI-Powered Future

  • Current Feature: Natural Language to `entities.json`.
  • Example: "create a user with a name and an email"
  • Future Possibilities: AI-generated UI, automated test creation, AI-driven code refactoring.

How it Works

  1. Write a simple sentence to describe your entities.
  2. Run the AI script: `python3 ai_entities.py "..."`
  3. Run the main generator: `python3 main.py`
  4. Run docker-compose: `docker-compose up`
  5. Your full application is running!
